# Sample authCapture terms (Base Sepolia)

These are sample terms for the deployed AgentKoinAuthCaptureArbiter v0.1 `0x8b4B3A8c6389a17AA7f66e18F59Afb36Cc9C453A`. The arbiter runs on AuthCaptureEscrow v1.1 `0xf96815976523E00e65Be8f34cA5e64b4f41EB19c`, chain 84532, with test funds only. The arbiter is an unaudited prototype; its source is verified on [Sourcify](https://repo.sourcify.dev/84532/0x8b4B3A8c6389a17AA7f66e18F59Afb36Cc9C453A).

- `terms.base-sepolia.json` has two parts: the x402 `outside-verdict` block (x402-foundation/x402#4324), and the arbiter-native `Terms` struct with its `termsHash`.
- `criteria.json` and `schedule.json` are the committed documents, stored as RFC 8785 bytes with no trailing newline. `criteriaHash` and `scheduleHash` are the sha256 of those exact bytes.
- `terms.schema.json` is the JSON Schema (draft 2020-12) for the sample.
- `verify.mjs` recomputes every hash offline. It needs only `viem`:
  ```
  node examples/authcapture/verify.mjs
  ```
- These files are generated by the AgentKoin arbiter SDK, which is not in this repository. That SDK is cross-checked against the arbiter contract.

The deployed v0.1 contract does not support:
- `resultDigest` in submit and verdicts
- signed `OutsideVerdict` verdicts
- the `BuyerAcceptance` record

On v0.1, the arbitrator is the zero address, so challenges are disabled.
